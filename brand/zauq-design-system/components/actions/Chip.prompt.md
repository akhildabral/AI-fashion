A choice — picks a value from a small set (day type, size, occasion).

```jsx
<div style={{ display: 'flex', gap: 'var(--space-2)' }}>
  <Chip on>Work</Chip>
  <Chip>Weekend</Chip>
  <Chip>Evening</Chip>
</div>
```

Do not confuse it with `Filter`: a chip picks a value and fills brass; a filter narrows a set and takes a quiet ink wash. Brass keeps meaning "act" or "here".
