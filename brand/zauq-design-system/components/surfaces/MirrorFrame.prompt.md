The Mirror room's hero object — where a try-on render appears.

```jsx
<MirrorFrame style={{ maxWidth: 420 }}>
  <img src={render} alt="You, in tonight's look" className="zq-mirror-reveal" style={{ display: 'block', width: '100%' }} />
</MirrorFrame>
```

Distinct from `Arch`: a 3px bezel, a taller crown, and a near-black glass ground rather than a lit vitrine — so an empty mirror stays atmospheric instead of looking like a blank card. Pair the render with `.zq-mirror-reveal`.
