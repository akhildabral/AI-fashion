The brand name set as live type — use it anywhere the ZAUQ name appears in UI chrome (header, auth screens, footers, splash).

```jsx
<Wordmark size={19} color="var(--text-strong)" />
<Wordmark size={64} ceremonial />
```

Never re-set the name in another face, never tighten the tracking, never add a tagline under it. `ceremonial` is for splash screens, packaging and invitations at 200px and up; in a header or nav bar it reads as an underline, so leave it off.
