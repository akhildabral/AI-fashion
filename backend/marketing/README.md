# ZAUQ — social ad kit

Generators for the Instagram/Facebook ad creatives, in the app's atelier
aesthetic. Backgrounds are generated by the app's own image model; the finished
ads are composed with the ZAUQ wordmark, a serif headline, and a CTA.

## Regenerate / extend

From `backend/` (needs the image env, i.e. the app's AI keys, and the brand
fonts installed — `assets/fonts/*.ttf`, and on macOS also as user fonts):

```
npx tsx scripts/ad-backgrounds.ts        # wave 1 raw backgrounds
npx tsx scripts/ad-backgrounds-2.ts      # wave 2 raw backgrounds
npx tsx scripts/ad-compose.ts            # compose finished ads (reads copy in-file)
npx tsx scripts/ad-contact.ts            # a contact sheet of all finals
npx tsx scripts/gen-adkit.ts             # the self-contained Ad Kit gallery page
```

Output goes to `backend/marketing/ads/{raw,final}` (gitignored — they're big
binaries). Override the location with `ADS_OUT=/some/dir`.

- **Add a background:** append a `{ key, prompt }` to the `SHOTS` array. Keep
  the atelier `BASE` prefix and leave negative space for a headline.
- **Add an ad:** append to the `ADS` array in `ad-compose.ts` (pick a `bg` key,
  a `size` — `sq` 1:1 / `pt` 4:5 / `st` 9:16 — hand-broken `head` lines, an
  `accent` line index for the gold italic, a `sub`, and a `cta`). Add the
  matching Meta copy to `marketing/ads/copy.json`.

`copy.json` holds the positioning, per-ad Meta Ads Manager copy (primary text,
headline, button, audience), the video/carousel concepts, and the run notes.
